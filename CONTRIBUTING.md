# Contributing

**Depos is an early preview.** The notes format and the extension still change often, so we do not accept pull requests yet. A pull request opened now is closed with thanks; it may be reopened when contributions open.

## What helps now

Open an [issue](https://github.com/kontratek/depos/issues).

- **Bug report.** Include the Depos version, your editor and its version (VS Code or a JetBrains IDE), your operating system, and the smallest supported manifest (for example `package.json`, `composer.json`, `Cargo.toml`, `pom.xml` or a Gradle build file) and notes file that show the problem.
- **Feature request.** Say what you tried to do and what stopped you.
- **Question about the format.** The reference is [`docs/format.md`](docs/format.md). If it does not answer your question, the document has a gap; open an issue.

Security problems: do not open an issue. See [SECURITY.md](SECURITY.md).

## When pull requests open

Contributions will be accepted under the [Contributor License Agreement, version 1](CLA-v1.md). You accept it once, by posting one sentence as a comment on your pull request; a check on the pull request shows the sentence. If you open a pull request before then, the same check asks for the signature. You do not need to sign; the pull request is closed either way.
